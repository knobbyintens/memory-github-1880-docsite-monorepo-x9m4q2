# Baseline blueprint example

This example shows the skeleton we copy for a new blueprint.

- `docs/task.md` and `docs/agent_system_prompt.md` are filled in first.
- Everything under `evaluation/`, `preprocess/`, `groundtruth_workspace/` and
  `initial_workspace/` is optional in content: stub it, adapt it, or leave it
  out entirely while the blueprint is still a draft.
